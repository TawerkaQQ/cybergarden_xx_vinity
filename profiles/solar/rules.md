# Правила извлечения: тонкоплёночные солнечные элементы

Формат сдачи — `data/solar/submission_template/README.md`, пример правильного ответа — `data/solar/dev_gold`. Правила ниже выведены из эталона: в скобках статьи dev, где это видно.

## Отбор статей

- Расчётные и модельные работы без изготовленных образцов — `in_scope=false` с причиной (D006 — ab initio, D016 — численное моделирование). Больше ничего по такой статье не извлекаем.
- В dev 19 статей из 21 в области. Перовскиты — меньшинство: кестериты, CIGS, Sb2Se3, CdTe, a-Si встречаются так же часто.

## Значения (results)

1. Строка — один показатель одного прибора при одних условиях: прибор × измерение × агрегация × момент времени. Лучший прибор и среднее — разные строки.
2. Каждое упоминание — отдельная строка: аннотация, текст, каждая таблица, подписи к рисункам. Повторы связываются через `duplicate_of`, основная запись — из таблицы или рисунка (D002: R008 из Table 1, повторы R008-1 и R008-2).
3. `aggregation` — только если сказано: best, champion, record → `champion`; average, mean → `mean`; median → `median`. «typical» и отсутствие указания → пусто. Пустых в эталоне больше половины.
4. «Среднее ± отклонение» → `mean`, `spread_value`, `n_devices`, если число приборов указано.
5. Числа из чужих работ (введение, обсуждение, рекорды, предел Шокли–Квайссера, строки таблиц из прошлых работ, D015) → `cited`, в `cited_publication_id` ссылка как в статье (`ref. [11]`, `Bai et al., 2018`). Прибор, измерение и материал пустые.
6. Значение есть, но только в supplementary или только кривой на графике → `present_not_extractable`, значения нет, в цитате — на что ссылается статья (`Supplementary Table S2`). Числа, подписанные прямо на рисунке, извлекаются (D021, рис. 10).
7. Производные числа — не результаты: разности строк таблицы, «improved by 3.6%», «increases Voc by 80 mV». Они идут в замечания `derived_values`.
8. Фразу с максимумами разных приборов («up to 41% and 0.46 V») раскладываем по своим приборам (D022).
9. Одинаковые числа у разных приборов не склеиваем (D014). Тот же прибор в другой таблице новых записей не даёт (D019, D022).
10. Прямой и обратный ход развёртки, освещение спереди и сзади — разные измерения (D015).
11. Мини-модуль — `device_type=minimodule`, его Voc относится ко всему модулю (D007).
12. Стабильность: `retained_PCE` в % с `time_point` и `time_unit` (D003: 93 % через 1000 h). Начальный КПД перед испытанием тоже записываем. «PCE decline of over 20%» → сохранение меньше 80 % с примечанием.
13. `stabilized_PCE` — КПД при слежении за точкой максимальной мощности. `Jsc_EQE` — ток, проинтегрированный по EQE.
14. Оцениваются 11 показателей: PCE, Voc, Jsc, FF, Rs, Rsh, HI, Jsc_EQE, stabilized_PCE, T80, retained_PCE. Остальные (дефицит Voc, Vmpp, AVT) можно записывать, они не оцениваются.

## Нормализация

- Voc — V, Jsc и Jsc_EQE — mA/cm2, PCE, FF, HI, retained_PCE — %, Rs и Rsh — Ohm*cm2, T80 — h. Доля 0.71 → 71 %.
- Единица не указана («Voc = 0.85») — очевидная, с пояснением в `note`.
- Толщины — в нм, площадь — в см², ширина зоны — в эВ.

## Материалы, приборы, слои, измерения

- Каждый вариант поглотителя — отдельный материал: каждая концентрация добавки, температура обработки (D001, D012).
- `formula_normalized` пустой, если состав дан только навесками прекурсоров. `dimensionality` — только для перовскитов.
- Ширина зоны — только поглотителя, не ETL и не HTM. Метод: Tauc, EQE, PL; из литературы — `cited`.
- Каждый сравниваемый образец — отдельный прибор с полным стеком слоёв. Роль: `control` или `target`.
- У каждого прибора свой полный стек слоёв: общие слои (контакт на подложке, транспортные слои, тыльный контакт) повторяются у каждого прибора. Прибор без слоёв — ошибка. В эталоне у прибора 4–8 слоёв.
- Архитектура: перовскиты — `n-i-p` или `p-i-n`; CIGS, кестериты, Sb2Se3 на Mo — `substrate`; CdTe на стекле с TCO — `superstrate`.
- Слои от подложки, подложку не пишем. В структуре substrate первым идёт задний контакт (D017: SiOx → Mo → CIGS → CdS → i-ZnO → ZnO:Al → сетка → MgF2). CdS → `ETL`; i-ZnO, ZnO:Al, металлическая сетка → `front_contact`; просветляющее покрытие и барьер → `interlayer`. Исходное название — в `note`.
- Одно измерение = тип + направление развёртки. Спектр и интенсивность — как в статье. ISOS не назван → `other`, условия в `stress_conditions`.
- Измерений немного: одно на условия, `device_id` — список всех приборов, измеренных в этих условиях. Обычно в статье одно-два измерения ВАХ и по одному EQE, MPP и стабильности. Ход развёртки — отдельное измерение, только если значения даны отдельно для прямого и обратного хода; иначе `scan_direction` пустой.
- Формула поглотителя — обычной химической записью без дефисов и добавок: `CsPbI2Br`, `Cs0.15FA0.85PbI2.85Br0.15`, `Cu(In,Ga)Se2`. Добавки — в `additives`.
- Авторы — «Фамилия И.О.» через «; »; температура отжига — с единицей: `100 °C`.

## Источник

- `source_page` — номер страницы в PDF с 1.
- `source_fragment` — дословный текст со страницы. Для значения из таблицы допустимо «Table 1, строка <подпись строки>» при заполненном `source_table`.
